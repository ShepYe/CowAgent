## 兼容与失败恢复

说明受影响旧数据／接口的读写、迁移和保留；故障后的数据状态、回滚／恢复及限制。涉及 Provider 或索引变更时，按影响说明旧配置、模型能力、索引格式的兼容，以及重建／回退期间的可用性与引用连续性。涉及消息和任务时，承接重复执行、部分成功和重启恢复契约。

关键技术未知写明隔离探针、通过标准和受阻任务；未决业务取舍单独标记，不写成已确认规则。
