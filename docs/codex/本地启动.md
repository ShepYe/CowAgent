# Windows 本地源码启动

在仓库根目录运行：

```powershell
.\start-personal.cmd
```

根目录的 `start-personal.cmd` 调用 `scripts/start-personal.ps1`，从源码启动现有 Electron 桌面端和 Python 后端，不经过 PyInstaller 或 NSIS 打包。

## 环境与依赖

本机需要预先安装 Python 3.11 和 Node.js 18+。启动脚本优先复用仓库中的 `.venv`（Python 3.11）及 `desktop/node_modules`；按 `requirements.txt` 与 `desktop/build/requirements-desktop.txt` 检查当前平台需要的 Python 依赖及版本，缺失或不匹配时自动补齐，缺 pip 时先离线引导安装 pip。缺少虚拟环境时自动创建，缺少桌面端依赖时通过 `npm ci` 安装。首次补齐项目依赖需要联网。

## 启动参数

以下命令均在仓库根目录执行：

| 用途 | 命令 |
| --- | --- |
| 默认源码启动 | `.\start-personal.cmd` |
| React 热更新开发 | `.\start-personal.cmd -Dev` |
| 仅安装或补齐依赖，不启动 | `.\start-personal.cmd -SetupOnly` |
| 仅检查环境，不安装、不启动 | `.\start-personal.cmd -CheckOnly` |
| 使用独立的调试数据目录 | `.\start-personal.cmd -DataDir .\local\source-debug` |

`-Dev` 使用 Vite 为 React 提供热更新；修改 Python 或 Electron 主进程后，需要停止并重新运行启动命令。

从其他目录也可通过完整入口路径执行，例如：

```powershell
& 'D:\CodeAndDesign\CowAgent\start-personal.cmd' -Dev
```

## 数据、日志与停止

`-DataDir <路径>` 接受绝对路径或相对路径，相对路径按仓库根目录解析。该参数覆盖 `COW_PERSONAL_DATA_DIR`；未传入时沿用该环境变量，环境变量也未设置时默认使用 `%USERPROFILE%/.cow-personal`。

默认数据根与个人安装版共用。需要隔离调试资料时，使用 `-DataDir` 指定独立目录，例如：

```powershell
.\start-personal.cmd -Dev -DataDir .\local\source-debug
```

运行日志位于所选数据根的 `run.log`。在启动控制台按 `Ctrl+C`，停止本次启动的进程并保留资料；若 Windows 显示 `Terminate batch job (Y/N)?`，输入 `Y` 结束批处理。

`-Dev` 使用本机 5173 端口；端口被占用时会提示失败，保留原有进程。停止原来的调试实例后再运行。

启动脚本不自动配置凭据，也不自动启用 Embedding；需要使用相关功能时另行配置。
