## 已交付能力

- 复用 Electron/React 与原模型设置。定制名 CowAgent Personal、应用 ID `com.cowagent.personal`；默认数据根 `%USERPROFILE%\.cow-personal`，可通过 `COW_PERSONAL_DATA_DIR` 指定隔离目录。首次空目录初始化，不迁移官方资料，停用官方更新。
- 可信飞书本人绑定采用实例、app、tenant 与 open_id；私聊校验早于下载、模型和工具。任务固定内部本人身份，普通渠道兼容保留。
- SQLite 持久接收与事件历史、附件哈希原件、配置修订、重复/冲突处理、取消提交屏障、启动对账和独立通知回执。飞书元数据先持久化，异步下载与主 Agent 自主整理；桌面聊天附件和知识页均可进入此链路。
- PDF 物理页、DOCX 段落/表格、XLSX 工作表/单元格的全文解析和来源版本；XLSX 保留公式与缓存缺失事实，不重算。原件、候选、解析与当前发布分开；只有索引回读校验并提交有效指针后才称可检索。
- `knowledge_ingest` 和 `knowledge_source_action` 接入实际工具加载。主 Agent 沿用知识提示和 knowledge-wiki，自主决定用途。临时资料及派生上下文排除长期摘要；更正、撤回和托管页篡改过滤贯通搜索、回读和后续上下文。
- 显式 `embedding_enabled=false` 关键词模式，旧安装缺省行为兼容；接收时绑定配置修订，无法重建旧连接时失败并说明重新提交。无会话密钥借用或空 Embedding 配置自动出网。
- 知识页任务、原件、出处和版本视图，按状态提供补充、重试、取消和来源动作；本人绑定只接受受认证桌面入口。完整备份包含会话、附件、原件、来源、任务、通知；校验后恢复，保留恢复点和失败回滚。

本地工单位于 `.scratch/personal-assistant-foundation/issues/01-configuration.md`～`07-package.md`；分别链接规格与唯一执行安排。T-08 保持条件分支，C/D/E 后续路线保留。

安装包绝对路径：`D:/CodeAndDesign/CowAgent/desktop/release/CowAgent Personal-Setup-2.2.2-x64.exe`，版本 2.2.2，大小 200,390,810 字节；SHA-256：`b4da37ef28737abba4f959e130f39a9cae47fdd2e598bcab120e20bef47306fa`。2026-11-10 19:40 构建完成，未配置代码签名证书，未发布。

运行安装包，安装后从“CowAgent Personal”开始菜单/快捷方式启动。源码方式在仓库创建 Python 3.11 `.venv`、安装 requirements 与桌面依赖，然后从 `desktop` 执行 `npm run dev`。完整本地构建入口为 `desktop/scripts/build-personal.ps1`，依次构建后端和 NSIS，使用 `--publish never`。

默认数据根独立于官方 `.cow`。本次真实安装测试位于 `D:/CodeAndDesign/CowAgent/local/installed-app`，测试资料根为 `D:/CodeAndDesign/CowAgent/local/installed-profile`；其中只保存虚构厂商连接和生成夹具，不是用户正式配置。卸载和升级保留个人数据。

交付验证完成后已停止隔离测试桌面及本机替身，保留资料与证据目录。正式使用时运行安装包并从开始菜单启动，使用默认独立根配置本人账号；本机虚构厂商配置仅属于上述测试根。

完整备份与恢复均应先退出桌面并确认后端停止。在仓库 PowerShell 中设置 `$env:PYTHONUTF8='1'`，把 `$env:COW_DATA_DIR` 设为要备份的个人数据根，运行 `.venv/Scripts/python.exe -m cli backup --output <归档绝对路径.zip>`；个人配置会自动选择完整 v3 归档。恢复入口为 `.venv/Scripts/python.exe -m cli restore <归档绝对路径.zip> --yes`，目标数据根仍由 `COW_DATA_DIR` 指定；`--workspace <目标工作空间>` 可显式指定恢复位置。恢复后使用与该快照匹配的版本启动。
