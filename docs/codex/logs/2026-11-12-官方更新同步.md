## 兼容适配

- 运行时与模型设置 API 都排除新增 CowAgent 的隐式能力接管，保留其他供应商原有自动顺序。搜索必须事先固定绑定，Agent 单传 `provider=cowagent` 不能借聊天密钥启用搜索；绘图显式供应商缺密钥时返回未就绪，不借聚合商补路由。
- CowAgent 的有效端点和环境凭据在任务接收时进入内存配置快照并参与 `config_revision`，任务只持久化摘要标识；运行中及嵌套调用保留原连接，Bash 技能子进程沿用该快照。后续站点、语言或凭据变化无法重建旧修订时停止；未引用新渠道的旧配置修订计算保持原样。
- 模型渠道 API 新增可选字符串 `configured_api_base`，保存配置原值以区别运行时默认值；空串表示未填写，旧 API 缺字段时桌面保留有效地址。用户明确填写的国内站即使尚未配密钥，也不会被英文界面预填成全球站。GET 继续只读、密钥保持掩码，原保存锁与先落盘后发布行为保留。
- Electron 启动后端同时传 `COW_DEPLOYMENT=desktop` 和旧 `COW_DESKTOP=1`，避免继承的其他部署标识覆盖桌面身份；Personal 应用标识、独立数据根、默认关闭向量和官方更新门禁均保持。
- 原生 MCP 测试首次在 Windows 失败，原因是测试生成的含非 ASCII 字符 Python 脚本使用系统默认编码；改为 UTF-8 后复测通过，未改变 MCP 运行协议。
- 独立复核发现大小写／首尾空格的搜索渠道能被运行时识别、却未进入任务连接快照；绑定识别改为同样规范化，并补两种配置的环境轮换回归，防止运行中切换凭据或重启误认修订可用。
