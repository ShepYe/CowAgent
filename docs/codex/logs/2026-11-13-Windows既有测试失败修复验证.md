## 根因与修复

| 根因 | 修复及验证 |
| --- | --- |
| Windows 上跨线程关闭 Claude 流连接后，读取仍可能阻塞 | 流请求同时约束网络读取超时；看门狗和异常处理共用停顿判据。本机真实 HTTP 服务覆盖停顿、思考降级重试、已有可见输出不重试；另覆盖 ping 持续刷新和 eager 拒绝后重发。修前单例耗时超过断言上限，修后模型请求四组 91 项、Claude 全组 43 项通过。 |
| 下载技能写入时发生 LF→CRLF 转换；前言解析结束分隔符前多捕获 CR | URL 安装保留下载内容换行，前言正则统一消费结束分隔符前 CRLF。LF／CRLF 下载字节、描述注册与重新加载一致；新增 CRLF 用例修前 2 失败，修后技能相关 46 项通过。 |
| 测试替身缺字段或依赖环境残留配置 | 补全执行器媒体队列及分块管理器配置，显式设置缓存路由；PDF 用实际配置修订、离线能力凭据、生产媒体交付和证据发布流程。原生阅读相关 105 项通过，不放宽产品准入。 |
| 子进程缺 Windows 系统环境、中文管道编码不一致 | 隔离根保持不变，仅保留必要系统环境并固定 UTF-8；Bash 从字节 stdin 读取真实函数，避免 Windows 宿主路径被 WSL／Git Bash 误解。全文索引 13 项、CLI 指定组 36 项通过。 |
| 路径及文件操作测试假设 POSIX 行为 | 文件系统路径用 Path 比较，数据库规范路径用 POSIX 分隔符；固定夹具换行；读取字节与描述符元数据捕获后再替换文件；权限拒绝用定点故障注入；恢复 mtime 后未变化的签名按已有 TTL 过期。 |
| 本机没有创建符号链接的权限 | 用局部 helper 识别明确能力错误，其他文件系统错误继续抛出；拆分普通文件和链接分支，保留路径穿越、安全校验及共享知识无链接回退。路径组 218 项通过、61 项跳过，helper 的成功及错误分类另有验证。 |
| 仓库源码扫描误进入 ignored 的本地生成工具／依赖 | 扫描 Git 管理及未忽略的新 Python 源码，严格解析 UTF-8（接受合法 BOM），不遍历本地第三方运行库。 |

本轮产品修改局限于 Claude 流读取及技能文本保存／解析；其余为测试隔离、跨平台夹具和现有契约对齐。没有调整持久化格式、业务准入或模型提供方；测试使用隔离根、mock 或本机服务器。

## 联合验证与审核

最终命令：`.venv/Scripts/python.exe -m pytest tests -q --tb=short -rs --junitxml=local/legacy-failures-final.xml`（父进程 `PYTHONUTF8=1`）。结果 **7101 通过、239 跳过、106 个子测试通过、0 失败**，耗时 766.80 秒，退出码 0。JUnit 同样为 `failures=0`、`errors=0`。

跳过项包括 POSIX 专属搜索／shell／文件权限／FIFO、macOS 原生图像工具、需主动启用的已安装浏览器，以及本机无法创建的符号链接。没有 deselect；仅能力错误局部跳过，其他错误照常失败。38 条警告主要是既有弃用接口、测试线程退出和可选工具提示，未当作失败或静默过滤。
